## 💼 Projects

### 🗂️ [Goal Manager (Collaborative)](https://github.com/CodeNovaGZ/SimpleGoalTracker)
`TypeScript` `React` `TanStack Query` `Tailwind CSS` `Express` `PostgreSQL` `Prisma`

Collaborative goal-tracking web app with a dockerized Node/Express + PostgreSQL backend. I owned the entire frontend build.
- Structured the component architecture and routing, avoiding duplicate server requests through TanStack Query's automatic caching.
- Wired up 3 full user flows (auth, goal creation, tracking) by consuming REST endpoints connected to a real PostgreSQL database.
- Added Zod-based form validation to catch invalid data before it hits the API, plus responsive styling with Tailwind CSS.

**Status:** ✅ Functional MVP
